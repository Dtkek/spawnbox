# Spawnbox

Личный хостинг Minecraft для ПК на Windows. Панель ставит и запускает сервер, усыпляет его, когда все вышли, и будит, когда кто-то заходит. Друзья могут запускать сервер сами, а играть можно и с лицензией, и без.

## Запуск

Это обычная программа для Windows с установщиком. Python и права администратора не нужны.

1. Скачай [SpawnboxSetup.exe](https://github.com/Dtkek/spawnbox/releases/latest/download/SpawnboxSetup.exe) и запусти его. Если появится синее окно SmartScreen, нажми «Подробнее» и «Выполнить в любом случае»: файл не подписан.
2. После установки Spawnbox появится в меню «Пуск» и, если оставить галочку, на рабочем столе.
3. Если Windows спросит про брандмауэр, разреши доступ, иначе к серверу никто не подключится.
4. Выбери, с чего начать: своя сборка или новый сервер. Java скачается сама.
5. Прочитай и прими EULA Minecraft, затем нажми «Запустить».

### Окно и значок у часов

Крестик только прячет окно: Spawnbox остаётся работать у часов, и друзья могут запускать сервер. Открыть окно можно щелчком по значку или ярлыком. В меню значка (правая кнопка) есть запуск и остановка сервера и пункт «Выйти». При выходе сервер сохранит мир и выключится.

На вкладке «Настройки» можно включить запуск вместе с Windows: тогда Spawnbox сразу уходит к часам, без окна. Там же можно разрешить компьютеру засыпать. По умолчанию, пока Spawnbox работает, компьютер сам не засыпает, потому что спящий компьютер друзья разбудить не смогут.

Если на компьютере нет компонента WebView2, панель откроется в браузере, а всё остальное будет работать так же. В Windows 11 он есть, в Windows 10 обычно приходит с обновлениями.

### Обновление и удаление

Чтобы обновить, запусти новый установщик поверх старого. Он сам закроет Spawnbox и дождётся, пока сервер сохранит мир. Удаляется программа как обычно, через «Установленные приложения». Миры, бэкапы и настройки при этом остаются в папке данных.

Если что-то пошло не так, смотри журнал: файл `logs\spawnbox.log` в папке данных. Открыть её можно кнопкой в «Настройках».

Для запуска из исходников (`start.bat`) нужен Python 3.11 или новее. Без `pip install -r requirements-desktop.txt` панель откроется в браузере.

## Как зайти в игру

- **С этого ПК:** адрес `localhost`.
- **Из той же сети:** адрес показан на главной вкладке панели.
- **Из интернета:** нужен внешний адрес, см. ниже.

Если сервер спит, игрок увидит это в списке серверов. Первая попытка войти разбудит сервер. Когда он запустится, можно заходить снова: обычному серверу нужна примерно минута, большой сборке — несколько минут.

## Своя сборка и мир

Вкладка «Импорт сборки» переносит сборку на Fabric, Forge или NeoForge вместе с миром. Исходные файлы не меняются, панель всё копирует.

1. Укажи папку сборки в лаунчере: в ней есть папки `mods` и `saves`. Подойдёт и архив `.zip`, и сам мир.
2. Нажми «Проверить». Панель определит ядро и версию и покажет, что нашла. Проверь это и при необходимости поправь.
3. Выбери мир и напиши свой ник: вещи из одиночной игры перенесутся этому игроку.
4. Нажми «Импортировать», а когда импорт закончится, нажми «Запустить».

Что панель делает сама:

- ставит ту же версию ядра, что у сборки;
- копирует `mods`, `config` и другие нужные серверу папки;
- откладывает моды только для клиента в `mods_client_only`: они часто роняют сервер;
- переименовывает мир латиницей;
- выделяет серверу до 8 ГБ памяти, если на компьютере столько есть.

У всех игроков должна быть такая же сборка. Ссылку на неё можно указать на вкладке «Доступ для друзей». Если сервер не запускается, причина обычно видна в консоли: чаще всего это мод, которому не хватает другого мода, или мод только для клиента, который панель не распознала.

Сборки на Quilt пока не поддерживаются. Экспорт сборки (`.mrpack` или архив CurseForge) содержит только список модов, поэтому сначала установи её в лаунчере и укажи папку.

## Игроки с лицензией и без

По умолчанию пускаются все (`online-mode=false`). Переключатель находится в «Настройках».

При таком режиме никто не проверяет ник, поэтому кто угодно может зайти под твоим именем и получить твои права. Защита зависит от ядра:

- **Paper:** панель сама ставит AuthMe и SkinsRestorer. При первом входе нужно написать `/register пароль пароль`, потом каждый раз `/login пароль`. Скин можно поставить командой `/skin Ник`.
- **Fabric:** панель сама ставит EasyAuth и, если нужно, Fabric API. Команды те же. Скины останутся стандартными, если их не поддерживает сама сборка.
- **Vanilla, Forge, NeoForge:** входа по паролю нет. Включи белый список (`whitelist add Ник` в консоли) и не выдавай права оператора.

Выбери режим до начала игры: при его смене у игроков меняется идентификатор, и вещи с прогрессом остаются у старого.

## Доступ для друзей

По умолчанию сервер может запустить любой, кто знает адрес страницы для друзей: код не нужен. Кроме статуса и кнопки запуска, на этой странице ничего нет. Запуск работает, только пока твой компьютер включён и Spawnbox работает, хотя бы у часов. Чтобы мир запускался при выключенном компьютере, нужен арендованный сервер.

Чтобы пускать только своих, выключи «Любой, у кого есть ссылка» на вкладке «Доступ для друзей» и выдай личные коды. Код можно отозвать в любой момент. Войти в игру можно и без страницы: если сервер спит, вход разбудит его. Чтобы это могли только свои, включи белый список.

Какие порты для чего нужны:

| Порт | Назначение | Открывать наружу |
|---|---|---|
| 25565 | игра | да |
| 8766 | страница для друзей | да |
| 8765 | админка | **нет, никогда** |
| 25566 | сам сервер, только `127.0.0.1` | нет |

**Не направляй туннель на порт 8765.** Через него можно загрузить плагин, то есть запустить любую программу на твоём ПК. Страница для друзей идёт по обычному HTTP, поэтому код можно перехватить, но он даёт только запуск сервера.

## Как открыть сервер в интернет

Подойдёт любой из вариантов. Полученные адреса впиши в «Настройках», и они появятся в панели и в ссылках для друзей.

- **Проброс портов на роутере:** перенаправь 25565 и 8766 на этот ПК. Работает, если у провайдера белый IP.
- **Туннель** вроде [playit.gg](https://playit.gg): не нужен белый IP. Создай туннели на порты 25565 и 8766.
- **Общая VPN-сеть** вроде Radmin VPN или ZeroTier: все ставят одну программу и играют как в домашней сети. Наружу ничего не открывается, поэтому это самый безопасный вариант.

## Что важно знать

- Сервер доступен, только пока ПК включён. Пока Spawnbox работает, Windows не уходит в сон сама, если это не выключено в настройках.
- Бан по IP не работает: за шлюзом все игроки выглядят как `127.0.0.1`. Бан по нику работает.
- Плагин или мод — это программа с теми же правами, что и панель. Скачивай их только из проверенных мест.
- Все данные лежат в `%LOCALAPPDATA%\Spawnbox`: сервер, миры, бэкапы и Java. Если в имени пользователя Windows есть кириллица, они лежат в `C:\ProgramData\Spawnbox`: с кириллицей в пути Java и часть модов могут не работать. Точный путь и кнопка, открывающая папку, есть в «Настройках». Чтобы перенести всё на другой ПК, скопируй эту папку и поставь там Spawnbox.

## Для разработки

Тесты работают на заглушке сервера и ничего не скачивают: `python tests/test_spawnbox.py`

Установщик собирает GitHub Actions при каждом push в `main`: PyInstaller собирает приложение, Inno Setup (`packaging/spawnbox.iss`) — установщик. Затем `tests/smoke_windows.py` ставит его на раннере, проверяет окно и все ядра, обновляет и удаляет программу, и только после этого обновляется релиз `latest`. Значок рисует `packaging/make_icon.py`.
