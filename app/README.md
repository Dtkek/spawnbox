# Spawnbox

Личный хостинг Minecraft для ПК на Windows. Панель ставит и запускает сервер, усыпляет его, когда все вышли, и будит, когда кто-то заходит. Друзья могут запускать сервер сами, а играть можно и с лицензией, и без.

## Запуск

Ни Python, ни распаковка не нужны: всё находится в одном файле.

1. Скачай [spawnbox.exe](https://github.com/Dtkek/spawnbox/releases/latest/download/spawnbox.exe).
2. Запусти его. Если появится синее окно SmartScreen, нажми «Подробнее» и «Выполнить в любом случае»: файл не подписан.
3. Если Windows спросит про брандмауэр, разреши доступ, иначе к серверу никто не подключится.
4. Откроется панель: http://127.0.0.1:8765. Во вкладке «Версия» выбери ядро и версию и нажми «Установить». Java скачается сама.
5. Прочитай и прими EULA Minecraft, затем нажми «Запустить».

Окно программы должно оставаться открытым, пока сервер нужен. Если его закрыть, сервер сохранит мир и выключится.

Для запуска из исходников (`start.bat`) нужен Python 3.11 или новее.

## Как зайти в игру

- **С этого ПК:** адрес `localhost`.
- **Из той же сети:** адрес показан на главной вкладке панели.
- **Из интернета:** нужен внешний адрес, см. ниже.

Если сервер спит, игрок увидит это в списке серверов. Первая попытка войти разбудит сервер, а через минуту можно заходить снова.

## Игроки с лицензией и без

По умолчанию пускаются все (`online-mode=false`). Переключатель находится в «Настройках».

При таком режиме никто не проверяет ник, поэтому кто угодно может зайти под твоим именем и получить твои права. Защита зависит от ядра:

- **Paper:** панель сама ставит AuthMe и SkinsRestorer. При первом входе нужно написать `/register пароль пароль`, потом каждый раз `/login пароль`. Скин можно поставить командой `/skin Ник`.
- **Vanilla, Fabric, Forge:** входа по паролю нет. Включи белый список (`whitelist add Ник` в консоли) и не выдавай права оператора.

Выбери режим до начала игры: при его смене у игроков меняется идентификатор, и вещи с прогрессом остаются у старого.

## Доступ для друзей

Вкладка «Доступ для друзей» выдаёт личный код. Друг открывает ссылку и может посмотреть статус и запустить сервер. Больше ему ничего не доступно. Код можно отозвать в любой момент.

Какие порты для чего нужны:

| Порт | Назначение | Открывать наружу |
|---|---|---|
| 25565 | игра | да |
| 8766 | страница для друзей | да |
| 8765 | админка | **нет, никогда** |
| 25566 | сам сервер, только `127.0.0.1` | нет |

**Не направляй туннель на порт 8765.** Через него можно загрузить плагин, то есть запустить любую программу на твоём ПК. Страница друзей идёт по обычному HTTP, поэтому код можно перехватить, но он даёт только запуск сервера.

## Как открыть сервер в интернет

Подойдёт любой из вариантов. Полученные адреса впиши в «Настройках», и они появятся в панели и в ссылках для друзей.

- **Проброс портов на роутере:** перенаправь 25565 и 8766 на этот ПК. Работает, если у провайдера белый IP.
- **Туннель** вроде [playit.gg](https://playit.gg): не нужен белый IP. Создай туннели на порты 25565 и 8766.
- **Общая VPN-сеть** вроде Radmin VPN или ZeroTier: все ставят одну программу и играют как в домашней сети. Наружу ничего не открывается, поэтому это самый безопасный вариант.

## Что важно знать

- Сервер доступен, только пока ПК включён. Пока панель работает, Windows не уходит в сон сама.
- Бан по IP не работает: за шлюзом все игроки выглядят как `127.0.0.1`. Бан по нику работает.
- Плагин или мод — это программа с теми же правами, что и панель. Скачивай их только из проверенных мест.
- Все данные лежат в `%LOCALAPPDATA%\Spawnbox`: сервер, миры, бэкапы и Java. Сам `spawnbox.exe` можно перемещать и обновлять, миры не пропадут. Чтобы перенести всё на другой ПК, скопируй эту папку.

## Для разработки

Тесты работают на заглушке сервера и ничего не скачивают: `python tests/test_spawnbox.py`

`spawnbox.exe` собирает GitHub Actions при каждом push в `main`. Он же прогоняет тесты на Windows и проверяет сам exe на настоящих Paper и Forge (`tests/smoke_windows.py`), а затем обновляет релиз `latest`.
